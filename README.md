# DPP4i-ACEi and Lung Cancer Study

This repository contains SAS code for the primary analysis of the association
between concomitant use of dipeptidyl peptidase 4 inhibitors and angiotensin-
converting enzyme inhibitors and lung cancer risk.

## External SAS macros

The following public macros are required or referenced by the code.

- Propensity score fine stratification and the supporting `table1` macro  
  Desai R. *Propensity score fine stratification SAS macro*. Harvard Dataverse,
  V5, 2020. https://doi.org/10.7910/DVN/U8JLCW

- `stddiff`  
  Yang DS, Dalton JE. *Standardized Difference: An Index to Measure the Effect
  Size Between Two Groups*. SAS Global Forum 2012, Paper 335.  
  https://support.sas.com/resources/papers/proceedings12/335-2012.pdf

- `OneToManyMTCH`  
  Parsons LS. *Performing a 1:N Case-Control Match on Propensity Score*.
  SUGI 29, Paper 165-29.  
  https://support.sas.com/resources/papers/proceedings/proceedings/sugi29/165-29.pdf
